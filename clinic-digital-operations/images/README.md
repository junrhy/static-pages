# Images Directory

This directory contains the professional images for the Continuum Clinic Ops website.

## Current Images (Sample/Placeholder)

**Note:** The following images are sample/placeholder images downloaded from Unsplash for development purposes. They should be replaced with final professional images that match the exact requirements below.

## Required Images

### 1. hero-office.jpg
**Location:** Home page hero section  
**Purpose:** Establishes professional, clinic-grade atmosphere  
**Requirements:**
- Clean, modern office interior OR professional meeting room OR system dashboard (blurred data)
- Neutral lighting, calm environment
- No people or staged photos
- Grayscale filter applied via CSS
- Low opacity overlay

**Why:** Creates immediate professional context without decoration. The subtle, grayscale treatment ensures the image supports rather than competes with content.

### 2. founder.jpg
**Location:** About page  
**Purpose:** Establishes founder credibility and professionalism  
**Requirements:**
- One professional headshot or portrait
- Neutral background (white, light gray, or subtle office environment)
- Professional attire
- Calm, confident expression
- No exaggerated emotions
- High quality, clear focus

**Why:** Builds trust through direct human connection. The professional presentation reinforces authority and accountability mentioned in the copy.

## Image Guidelines

- **Format:** JPG or PNG
- **Optimization:** Compressed for web, maximum file size 200KB each
- **Dimensions:** 
  - Hero image: 1920x800px minimum
  - Founder photo: 600x600px (square) or 600x800px (portrait)
- **Style:** Low saturation, consistent lighting, professional quality

## Notes

- All images should feel like they belong in a medical consulting firm or clinic administration office
- Avoid startup aesthetics, marketing imagery, or generic stock photos
- Images support structure and clarity, they do not decorate
- If images cannot be sourced that meet these requirements, consider removing them entirely rather than using substandard alternatives
