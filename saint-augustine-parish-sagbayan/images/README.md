# Parish images

Add your own images here and reference them in the HTML:

- **hero.jpg** (or similar) – Replace the hero background in `styles.css` by changing the `.hero-image` `background` URL to `url('images/hero.jpg')`.
- **parish.jpg** – For the About section: in `index.html`, replace the `.about-image-placeholder` div with `<img src="images/parish.jpg" alt="Saint Augustine Parish Church" class="about-image">` and ensure `.about-image` in `styles.css` has `width: 100%; height: 100%; object-fit: cover;`.

Optional: logo (e.g. `logo.svg`) for the navbar.
